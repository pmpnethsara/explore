# Explore Galle

A responsive travel-planning website for Galle, Sri Lanka, built with plain HTML, CSS and JavaScript.

## Features
- Browse and filter destinations, hotels, and restaurants.
- Open map searches and an official hotel website.
- Add places to a trip shortlist and remove them.
- Choose arrival date and trip length.
- Generate, copy, or download a simple itinerary.
- Responsive layout for desktop and mobile.

## Run on Arch Linux
1. Extract the ZIP file.
2. Open a terminal in the project folder.
3. Start PHP's local development server:

   ```bash
   php -S localhost:8000
   ```

4. Open <http://localhost:8000> in your browser.

You can also open `index.html` directly in a browser.

## Notes
- This is a front-end demo; it does not process bookings or payments.
- Images are loaded from Unsplash and fonts from Google Fonts, so those parts need an internet connection.
- Places, ratings, travel times, opening hours, and availability should be verified before travel.
- No framework or package installation is required.
